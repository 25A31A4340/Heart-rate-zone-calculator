# Heart Rate Zone Calculator

## Description
The Heart Rate Zone Calculator is a web application that calculates different heart rate training zones based on the user's age and resting heart rate. The application helps users understand workout intensity levels through a simple and interactive interface.

---

## Features
- Calculates heart rate zones instantly
- Simple and interactive user interface
- Responsive web design
- Displays workout intensity zones
- Easy navigation between pages
- ECG sound support
